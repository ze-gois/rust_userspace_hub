userspace_build

Build-time machinery for the freestanding stack. The build-side companion to userspace, versioned and released with the same ecosystem.

API docs crates.io GitHub
build-time no_std with_std tooling

Role in the ecosystem

userspace_build holds code needed while constructing freestanding userspace artifacts. Higher layers can consume it as a build dependency with with_std where host-side execution is intentional.

What exists today

  • Build-side target/file/memory machinery
  • with_std and no_std feature modes
  • Build dependency for freestanding members
  • Shared release line with userspace
