userspace

A process, from the bottom up. A no_std systems layer exploring what userspace needs below a conventional standard library.

API docs crates.io GitHub
no_std Linux x86_64 ELF memory

Role in the ecosystem

userspace concentrates process-facing machinery: low-level I/O, executable loading, memory, target-specific behavior, startup and panic paths.

Current surface

What exists today

  • Open/read/seek and low-level file I/O
  • ELF parsing and PT_LOAD mapping
  • PIE / ET_DYN and PT_INTERP handling
  • Heap, pages and process stack work
  • Architecture and operating-system target modules
