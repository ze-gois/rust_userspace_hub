One workspace. Nine repositories. One release line. Integration workspace and publication hub for the userspace.party Rust ecosystem.

API docs crates.io GitHub

Role in the ecosystem

The hub pins the eight child repositories as Git submodules and patches their crates.io dependencies to those local sources. Standalone crates stay independent; integration happens here.
